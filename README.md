# PlatinumStore App

Мобильное приложение для интернет-магазина [replatinum.ru](https://replatinum.ru).
Разработано на Flutter с использованием REST API (PHP, 1C-Bitrix).

Пустая корзина, единый размер кнопок карточек и история «Вы смотрели»: [документация](docs/CART_AND_HISTORY_UI.md).

## 🚀 Быстрый старт

### Разработка и отладка (Веб)
Для запуска в браузере (Chrome) с отключенной проверкой CORS (необходимо для работы с API на локальном этапе разработки):
```bash
flutter run -d chrome --web-browser-flag "--disable-web-security"
```

### Отладка Android и release APK

Локальный `flutter build` запрещён инструкциями `AGENTS.md`. Для проверки интерфейса на запущенном эмуляторе:

```powershell
flutter run --no-pub -d emulator-5554 --debug
```

Release APK собирает GitHub Actions после разрешённой отправки в `main`. Изменения шапки проверены локально; 02.10.2026 пользователь разрешил отправку в `main` для сборки через GitHub Actions.
## 🔗 Структура проекта

* `lib/data/api/api_service.dart` — Основной класс для работы с REST API (Dio).
* `lib/data/models/` — Data-классы (модели) для парсинга JSON ответов.
* `lib/ui/screens/` — Основные экраны приложения (Главная, Каталог, Корзина, Профиль, Детальная карточка товара).
* `lib/ui/widgets/` — Переиспользуемые UI компоненты (Шапка, Слайдер, Карточки товаров).
* `lib/providers/` — Управление состоянием (например, `CartProvider` для корзины).

## Главная и навигация
Компактная шапка без логотипа, три плитки, затухание при прокрутке и закреплённый поиск. Нижняя навигация содержит четыре вкладки. Карточки каруселей компактные; непарная карточка остаётся слева, отметка «Без RuStore» берётся из API.

Подробности реализации, размеры, проверки и ограничения: [docs/HEADER_UI.md](docs/HEADER_UI.md). История изменений: [APP_REPORT.md](APP_REPORT.md).
## Автоматическая сборка
Каждый push в ветку `main` запускает GitHub Actions: проверку кода и сборку release APK. Готовый APK доступен в артефактах завершённого запуска во вкладке Actions.
