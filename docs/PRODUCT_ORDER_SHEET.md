# «Под заказ» — 02.10.2026

В деталях товара обе кнопки покупки для недоступного SKU открывают компактную шторку поверх нижней навигации (`useRootNavigator`). Состав соответствует предоставленному скриншоту сайта: заголовок и закрытие, пояснение о сроках/цене, фото и название выбранного варианта, имя, телефон, необязательный комментарий, зелёная кнопка с белым текстом «Заказать товар». Убраны отдельные кнопки звонка/политики и прежний дополнительный блок согласия. Шторка прокручивается при открытой клавиатуре и увеличенном шрифте.

Имя обязательно, телефон проверяется на 10 цифр после +7; ввод с +7/8 нормализуется. Во время отправки поля/кнопка заблокированы. Ошибка не очищает введённые данные, доступен повтор. Сообщение об успехе появляется только после подтверждения обработчика.

Приложение отправляет JSON в существующий `https://replatinum.ru/local/ajax/preorder.php`: `productId` — ID выбранного SKU, `productTitle` — его имя, `name`, `phone` без префикса +7, `comment`. Токен Telegram и список получателей остаются на сервере, в приложение не добавлялись. В изученной опубликованной версии обработчик разрешает карточку/родителя и добавляет `#sku=ID` в ссылку; возвращает `success=true`, только если хотя бы одна отправка получила HTTP 200 и Telegram `ok=true`. Это не подтверждает доставку каждому получателю списка.

Текущая безопасная GET-проверка живого обработчика: HTTP 200, `success=false`, `Invalid request`; заявка и уведомление этим запросом не создаются. Исходник сверялся с локальным опубликованным снимком и протоколом `H:/Codex/Replatinum_sait/codex/backups/preorder-product-link-20261001/MANIFEST.md`. Сервер и настройки Telegram в этой задаче не менялись.

57 Flutter-тестов прошли; анализатор без замечаний. Новые проверки с подменённым транспортом подтверждают точный URL/JSON/SKU, отказ при `success=false`, успех при `success=true`. Widget-тесты при ширине 320 и масштабах текста 1/2 проверяют валидацию, нормализацию телефона, ошибку/повтор, блокировку при отправке, закрытие шторки и отсутствие лишних контролов. Эти проверки не являются доказательством реальной доставки Telegram. Для сквозной проверки запрошены тестовые имя и телефон; реальное уведомление пока не отправлялось.
