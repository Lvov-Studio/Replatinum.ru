# Пустая корзина и история просмотров — 02.10.2026

Пустая корзина: светлая шапка «Корзина», пояснение, тёмная кнопка с белым текстом «В каталог», ниже «Хиты продаж» и «Новинки». Подборки загружаются через существующий `getHomeProducts`; используются общие карточки главной, реальные цены и SKU, избранное, сравнение и серверный признак RuStore. Загрузка, ошибка с повтором и пустая подборка обрабатываются каруселью. Нажатие «В каталог» открывает корень каталога. Наполненная корзина и оформление заказа сохраняют прежнюю логику.

Для карточек каталога, главной и подборок корзины действует единый стандарт кнопки: визуальная высота 40 logical px, внешний размер по высоте 48, белый текст 13/w600, скругление 7, фон `AppColors.darkAccent`. Ширина зависит от карточки. У «Под заказ» тот же стандарт.

«Вы смотрели» расположено под новостями и обзорами. Компактные горизонтальные карточки показывают фото, название и цену последнего выбранного варианта. Нажатие открывает модель с сохранённым SKU. У неизвестной цены — «По запросу». Цена в истории является снимком на момент просмотра; при открытии детали запрашиваются заново.

`RecentProductsProvider` хранит до 20 моделей в `recent-products.json` в каталоге поддержки приложения. Повторный просмотр поднимает модель в начало и обновляет её вариант, без дублирования модели. Запись происходит после успешной загрузки деталей и при выборе варианта; избранное и сравнение хранятся отдельно. Загрузка истории завершается до новой записи, операции записи последовательны. История остаётся на устройстве, без авторизации и серверной синхронизации. При пустой истории блок скрыт; недоступное хранилище не блокирует покупку.

Проверка: полный набор 50 Flutter-тестов прошёл, анализатор без замечаний. Покрыты ограничение и порядок истории, восстановление SKU/цены после создания нового провайдера, повреждённый файл, скрытый/заполненный блок и пустая корзина при ширине 320 и масштабе текста 1/2. На Pixel 7 API 35 с живым API проверены пустая корзина, обе подборки и появление реально открытого товара под новостями; файл истории содержит выбранный SKU. Изменение общего размера кнопок дополнительно проверено тестами каталога, каруселей и истории. Физическое устройство и release APK локально не проверялись. Сайт и сервер не изменялись.

По кабинету пока только рекомендация: гостю доступны общие пункты и локальные сохранённые товары, для личных данных и заказов нужен вход с возвратом в выбранный раздел. Авторизация в рамках этих изменений не реализована.

Уточнение карточек блога: убран разделитель перед «Читать», обложка получила отступы 10 logical px сверху и сбоку. Изображение отображается целиком (`BoxFit.contain`), чтобы надписи внутри обложки не обрезались. Ссылка «Читать» использует контрастный фирменный зелёный `primaryText`.
