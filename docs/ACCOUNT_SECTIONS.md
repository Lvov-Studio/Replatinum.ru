# Разделы кабинета — 02.10.2026

Изменения подготовлены к общей отправке в GitHub по разрешению пользователя. Локальная release-сборка не запускалась. Эмулятор обновлён через Flutter debug.

## Готово

- Личные данные: имя, фамилия, email; телефон только для чтения. Сохранение через текущую Bitrix-сессию сайта.
- Заказы: только заказы текущего пользователя, пагинация, статус, сумма, детали с товарами и доставкой. Изменение/отмена/уточнение оплаты через поддержку.
- Адрес доставки: общие с сайтом PERSONAL_CITY / PERSONAL_STREET.
- Избранное: UF_FAVORITES аккаунта; вход читает список сайта и не переносит гостевые товары автоматически.
- Сравнение: PLATINUM_COMPARE в WebView приложения, как браузерный список сайта. Между разными браузерами/устройствами список не синхронизируется.
- Помощь: телефон, Telegram, Max, контакты, раскрывающиеся вопросы, доставка и гарантия.
- Единые светлые карточки, зелёные иконки, мягкие разделители; формы без счётчиков символов, ограничение длины сохранено. Выход по центру.
- Пустые заказы, избранное и сравнение предлагают каталог. Пустая категория показывает пояснение и переход к другим разделам; при активных фильтрах предлагает сброс.
- Меню скрывает «Войти» при авторизации; после выхода или истечения сессии кнопка возвращается. Общий AccountSession отражает состояние контроллера кабинета.

## Безопасность и данные

account.php опубликован отдельным обновлением одного файла; оригинальные обработчики SMS не менялись. POST + Bitrix CSRF, no-store, текущий USER_ID определяется сервером. Чужой order_id фильтруется до чтения товаров и свойств заказа. Поля профиля/адреса ограничены белым списком. Токены провайдеров в приложение не передаются.

Гостевые списки сохраняются отдельно; аккаунтные списки не записываются в гостевой JSON. При выходе восстанавливается гостевой список. Удалённые товары остаются доступными для удаления из списка.
