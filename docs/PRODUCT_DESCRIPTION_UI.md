# Описание внутри карточки — 02.10.2026

«Подробнее» раскрывает описание вниз в текущей карточке, «Свернуть» возвращает превью 240 logical px. Отдельный экран описания удалён. Простые описания используют `flutter_html`; оформленные HTML-блоки сохраняют CSS сайта в WebView без внутренней прокрутки.

Высота оформленного описания измеряется по контейнеру `description-content` и обновляется через доверенный `ResizeObserver`, в том числе после загрузки изображений. JavaScript включён только для внедряемого приложением измерения: исходные скрипты/обработчики удаляются, CSP сохраняет `script-src 'none'`. Ссылки открываются прежним способом. Развёрнутый блок участвует в общей прокрутке карточки товара.

Для длинного блока Android использует Hybrid Composition вместо текстурной поверхности: исходная проверка полного WebView вызвала сбой VizWebView. После смены способа композиции на эмуляторе проверено раскрытие CSS-описания iPhone 17 Pro Max, общая прокрутка до последнего раздела и «Свернуть» без падения. Высота следует реальному содержимому, отдельной внутренней прокрутки нет.

`flutter analyze --no-pub` без замечаний; весь набор из 62 тестов прошёл. Профильные тесты проверяют сохранение CSS, удаление исполняемого HTML, варианты, цены и расчёт рассрочки. Android-проверка: Pixel 7 API 35, 1080×2400, density 420. iOS и физический телефон не проверены.
