# Исправления по проверке телефона — 08.10.2026

## Приложение

SMS: заголовок 20 px, поле 168 px с плотными отступами, кнопка 48 px со скруглением 12 px. Сохранены одноразовое автозаполнение, ограничение четырьмя цифрами, изменение номера, повторная отправка и защита занятости. Проверены ширины 320/360/600 и масштаб текста 200%.

Главная: вместо загрузки всех страниц для предварительной полки запрашиваются первые 12 моделей. Детали старого API загружаются группами по четыре параллельно; порядок, выбранные отмеченные SKU, предупреждения RuStore, цены и свойства сохранены. Полка ограничена 12 карточками, «Посмотреть все» по-прежнему открывает полный каталог. Общий каталог не ограничен этой выборкой.

Живой замер с компьютера: get_products new 1,52 с (2 модели), hit 1,00 с (5 моделей); четыре проверенных оригинала изображений 159570–386510 байт, скачивание 1,05–2,03 с. Это отдельные запросы с компьютера, не замер на телефоне. Спиннер полки ждёт данные и детали, а не декодирование картинок.

Проверки: analyze без замечаний; 163 теста успешно. Регрессия проверяет единственный запрос списка, отсутствие полной пагинации и одновременно четыре незавершённых запроса деталей. Макет SMS использует тестовый gateway без сети/SMS: test_support/account_code_preview.dart.

## Ошибка заказа

Живой local/ajax/order/create.php скачан через FTP. Сообщение со скриншота выдаёт catch внутри транзакции и скрывает оригинальное исключение. Ранее опубликованная замена CSaleBasket::Add на BasketTable::add уже присутствует. Повторять её как новое исправление нельзя. Точная причина текущего отказа не подтверждена.

Подготовлена диагностика одного обработчика: stage order/basket/properties, случайный код ошибки и закрытый журнал вне DOCUMENT_ROOT. Тело запроса и cookie не записываются. Диагностика не опубликована до отдельного разрешения сервера. Реальные заказы, заявки и SMS в ходе проверки не отправлялись.
