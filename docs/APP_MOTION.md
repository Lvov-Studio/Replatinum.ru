# Плавность интерфейса — 08.10.2026

Сохранены стандартные платформенные переходы MaterialPageRoute (Android predictive back) и физика ScrollView. Без глобальной замены на iOS bounce, scroll-reveal, задержек открытия страниц и дополнительных зависимостей.

## Изменения

- Нижнее меню: короткий отклик 180 мс, easeOutCubic, InkWell и семантика выбора. IndexedStack и отдельные Navigator сохраняют позицию/историю вкладок. При Remove animations длительность нулевая.
- Превью каталога, новинок/хитов и просмотренных товаров: ResizeImagePolicy.fit с размером декодирования по физическому слоту, шаг 64 px, максимум 1024 px. Сохраняются пропорции. Дисковый кэш хранит оригинал; полноэкранные фото не уменьшались. Появление 180 мс, синхронно кэшированные фото без повторного fade.
- Главная: загрузка товарной полки резервирует её итоговую высоту, уменьшая сдвиг контента при поступлении ответа.
- Баннеры: автопрокрутка останавливается на скрытой вкладке, при перекрывающем маршруте, в фоне и при Remove animations. Возобновляется при возвращении. Для смены слайда easeOutCubic.
- Каталог: отфильтрованный/отсортированный список и фасеты вычисляются один раз на состояние, а не повторно для каждого счётчика. Любое уведомление инвалидирует кэш, включая частичные ответы API.
