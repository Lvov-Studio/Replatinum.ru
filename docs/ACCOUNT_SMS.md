# Кабинет и SMS — 02.10.2026

Статус: изменения подготовлены к общей отправке в GitHub по разрешению пользователя. Два серверных адаптера опубликованы с SHA-256 readback. Один запрос SMS принят сервером через эмулятор, получение SMS и вход подтверждены пользователем и эмулятором. Вход подтверждён по коду пользователя; профиль и пустые заказы прочитаны, после hot restart вход восстановлен без повторного SMS.

Кабинет открывает форму номера с маской `+7 (999) 123-45-67`, затем четырёхзначного кода. Повторное SMS ограничено таймером 60 секунд и блокировкой двойного нажатия. Для нового пользователя предусмотрены имя, фамилия и согласие. После входа доступны личные данные, свои заказы с пагинацией и выход. Избранное и сравнение остаются доступными гостю.

Авторизованному пользователю меню не показывает «Войти». Разделы и проверки описаны в [ACCOUNT_SECTIONS.md](ACCOUNT_SECTIONS.md). Меню «Войти» имеет высоту 48 logical px и переключает на тот же кабинет. Стикеры главной, каталога и рекомендаций корзины используют единый ProductBadge: спокойный зелёный фон, «Хит», «Новинка», «Акция», позиция слева сверху.

Вход использует существующие обработчики сайта, Bitrix-сессию и SmartCaptcha в WebView. Нативный интерфейс получает только результат операций; ключи SMS-провайдера в приложение не добавляются. Проверочный WebView допускает основной документ только на HTTPS replatinum.ru и проверяет nonce сообщений. Сессия хранится механизмом cookies WebView, её сохранение после перезапуска требует живой проверки.

Нужны два новых файла сайта: `/local/api/mobile/v1/account.php` и `account_bridge.php`. Без них форма сообщает об ошибке подключения и не отправляет SMS. Существующие check_phone.php, verify_code.php, register.php используются без правок. Контракт и ограничения описаны в проекте сайта: docs/site/mobile-account-api-20261002.md.

Проверено: 94 Flutter-теста, анализатор без замечаний. Покрыты маска, повторные запросы, регистрация, истечение сессии, профиль и заказы, переход из меню, размеры 320/360/600 px и увеличенный шрифт. Эти проверки используют mock gateway и не подтверждают доставку SMS или работу живой Bitrix-базы.

Для реальной проверки пользователь разрешил одно SMS на указанный в чате номер и предоставил код. До публикации серверных адаптеров SMS не отправлялось.
