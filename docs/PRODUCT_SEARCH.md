# Поиск товаров — 02.10.2026

Приложение использовало `/local/api/mobile/v1/search.php`: цены и изображения брались из родительского товара, сортировка SORT/NAME, без синонимов сайта. Живой запрос «17 pro» отдавал iPhone 17 Pro Max с нулевой ценой и фен HD17; «айфон 17 про» не находил ничего.

Приложение переведено на существующий `/local/ajax/search.php`, используемый сайтом. Ответ содержит results и corrected_query, цены строками с символом рубля, относительные миниатюры. API приложения преобразует цены в числа, абсолютные ссылки изображений, удаляет повторные ID. Числовой токен должен совпадать целиком: 17 не совпадает с HD17/117. Точные фразы поднимаются выше; внутри одинаковой релевантности сохраняется порядок сайта. Синонимы и исправления берутся с сервера, локальный список брендов не дублируется.

Поиск сайта ограничен пятью результатами. Общий запрос «pro» на текущем сайте отдаёт товары Google/GoPro без цены; приложение честно показывает «Под заказ», не выдумывает цену и не обещает наличие. Эта правка улучшает отображение и совпадения среди возвращённых кандидатов, не превращает серверный autocomplete в полный поиск всего каталога. Для расширения выдачи и улучшения широкой релевантности понадобится отдельная серверная правка.

Интерфейс: debounce 350 мс; предыдущая выдача сразу скрывается при изменении запроса, старые ответы не становятся актуальными. Запросы короче двух символов не отправляются, в том числе при подтверждении клавиатурой. Цена форматируется с разделителями, 0 ₽ заменено на «Под заказ», фото целиком помещается в миниатюре. Ошибки не показывают внутренний exception, есть «Повторить».

Открытие результата: ID передаётся как initialOfferId. Обработчик деталей распознаёт и модель, и SKU. Точное предложение имеет приоритет; для результата основной модели выбирается вариант с показанной в выдаче ценой. Свежая цена карточки остаётся источником истины, старое значение выдачи не подменяет её.

Проверки: 83 Flutter-теста прошли, flutter analyze без замечаний. Проверены формат цен, относительные фото, corrected_query, HD17/117, дедупликация, устаревшие ответы, debounce, короткие запросы, retry, zero-price UI и выбор варианта при переходе. Живые чтения сайта: iPhone 17 Pro — 98 990 ₽, Pro Max — 104 990 ₽ для «17 pro» на момент проверки; реальные цены могут измениться. Серверные файлы не менялись и не публиковались.
