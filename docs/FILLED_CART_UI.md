# Наполненная корзина — 02.10.2026

Компоновка по референсу CMstore, с цветами Replatinum: выбор всех/отдельных товаров, удаление, избранное, количество, раскрываемая горизонтальная лента аксессуаров и отдельные детали заказа. «Защита устройств» — серая недоступная кнопка. Рассрочка онлайн не добавлена: действующие условия приложения предусматривают оформление в магазине.

Галочки меняют реальный состав `orderItems`, локальный предварительный итог и серверный `quote_cart.php`. Оформление без выбора/проверенной цены отключено. После успешного заказа удаляются только оформленные товары; остальные остаются. Заказ при проверке интерфейса не отправлялся.

Рекомендации используют свойство сайта `BASKET_ITEM_ACCESSORIES` родительской модели. В существующий `get_product_detail.php` добавлен совместимый массив `basket_accessory_ids`; каталог и цены не менялись. Данные аксессуаров приложение получает через тот же API деталей. Выбирается доступный SKU с положительной ценой; уже добавленные SKU скрываются из ленты. Ошибка имеет повтор загрузки, пустая связь скрывает «Рекомендуем». Нулевая цена отображается как «По запросу», добавление отключено, карточку можно открыть.

Живая проверка: модель 1596 (iPhone 17 Pro Max) возвращает `["2","6","8","10"]`, как в корзине сайта. Эти четыре аксессуара сейчас имеют нулевую цену. Положительная цена/выбор SKU/добавление покрыты тестом; реальные товары с нулевой ценой не добавлялись бесплатно. API опубликован после свежей копии, повторной сверки и проверки SHA-256 скачанного файла: `3273f85c740eac3b5a4ceb5210959c73103e21e415ea0896ac97a9ce10a165c0`. Серверный протокол: `H:/Codex/Replatinum_sait/codex/backups/app-cart-recommendations-20261002/`.

Уведомления добавления в деталях и карточках явно имеют `persist: false`, длительность 2 секунды и очищают предыдущую очередь. Это исправляет стандартное поведение Flutter, при котором snackbar с действием остаётся на экране.

Проверка: анализатор без замечаний; 62 теста прошли. Тесты корзины проверяют 320/411 logical px, выбор, отключённую защиту и добавление конкретного аксессуара. На Android-эмуляторе 1080×2400 проверены живые цены и лента рекомендаций. Физический телефон отдельно не проверен.
