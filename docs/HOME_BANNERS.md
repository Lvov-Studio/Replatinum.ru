# Баннеры главной — 08.10.2026

Изменения только Flutter-приложения. Сайт, API, изображения, ссылки и данные баннеров на сервере не менялись. Существующие незакоммиченные материалы сохранены вне публикации.

Зелёная кнопка «Купить» убрана. Весь баннер открывает назначение; небольшая текстовая подпись со стрелкой уточняет действие. Заголовок до трёх строк, высота растёт при увеличенном системном шрифте. Индикаторы позволяют выбрать слайд. При отключённых системных анимациях автопрокрутка выключена, ручной выбор мгновенный; при открытом назначении автопрокрутка приостанавливается.

## Переходы

`BannerDestination` принимает HTTPS-ссылки только replatinum.ru/www.replatinum.ru, без userinfo и нестандартных портов. Сопоставляет точный путь раздела и сокращённую ссылку из текущего API с локальной иерархией каталога. Дополнительные пути AirPods, Canon и Watch Series 12 сверены с живым меню сайта 08.10.2026. ID категории берётся из актуального API по code. Название баннера не используется для угадывания назначения.

| Ссылка текущего баннера | Экран приложения |
|---|---|
| /catalog/iphone-18-pro-max/ | iPhone 18 Pro Max |
| /catalog/iphone/ | iPhone |
| /catalog/iphone-duo/ | iPhone Duo |
| /catalog/airpods/ | AirPods |
| /catalog/fotoapparaty_canon/ | Canon |
| /catalog/galaxy-z-fold7-galaxy-z-flip7/ | Galaxy Z |
| /catalog/umnye_chasy_i_fitnes_braslety/apple_/watch-series-12/ | Apple Watch Series 12 |
| /catalog/, ID 2509 | Новый Replatinum на Северной, 364 |

Для кампании открытия ID 2509 задано явное исключение только в приложении, пока серверная ссылка остаётся /catalog/. При изменении её пути исключение перестаёт действовать. Дата 16.10.2026 взята из опубликованных условий оформления; часы нового магазина не выдумывались. Карта и телефон открываются только по отдельному нажатию.

Другой /catalog/ открывает вкладку каталога. Неизвестные страницы, включая пока не сопоставленные ссылки товаров, открываются на сайте во внешнем браузере с явной подписью «Подробнее на сайте». Небезопасные/пустые ссылки не нажимаются. Ошибка загрузки раздела показывает повторную попытку, не подменяет нужный раздел общим каталогом.

Раздел баннера использует отдельный ProductProvider, сохраняет фильтрацию по каноническому пути при повторной загрузке и не меняет текущий раздел вкладки каталога. Цена, варианты и покупка работают через существующий каталог приложения.
